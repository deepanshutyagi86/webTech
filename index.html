HTML — The Skeleton of Every Web Page
▼
🍼 Think of it like this

HTML is like the bones of a human body. Just like bones give your body its shape, HTML gives a web page its structure — headings, paragraphs, images, links. Without it, there's nothing to see!

Basic Document Structure

html · basic template
<!DOCTYPE html>
<html>
  <head>
    <title>My Page</title>    <!-- shown in tab -->
  </head>
  <body>
    <h1>Hello World!</h1>  <!-- biggest heading -->
    <p>This is a paragraph.</p>
  </body>
</html>
🔑 Key Points
  • <!DOCTYPE html> — Tells browser this is HTML5
  • <html> — Root tag; everything goes inside it
  • <head> — Invisible info (title, CSS links, meta tags)
  • <body> — The visible content users see
  • Tags come in pairs: <tag> opens, </tag> closes. Some are self-closing: <br>, <img>, <hr>
  • HTML is NOT case-sensitive, but always use lowercase — it's best practice
  • Attributes give extra info: <img src="dog.jpg" alt="A dog">

Text Formatting Tags

html · text tags
<h1>Biggest Heading</h1>    <!-- h1 to h6 -->
<p>Paragraph</p>
<strong>Bold text</strong>        <!-- semantic bold -->
<em>Italic text</em>            <!-- semantic italic -->
<br>                             <!-- line break (no closing) -->
<hr>                             <!-- horizontal rule/line -->

Forms — Collecting User Input

🍼 Simple idea

A form is like a paper form at a doctor's office — you fill in your name, tick some boxes, and submit. HTML forms do the same thing digitally and send data to a server.

html · form example
<form action="/submit" method="post">
  <input type="text" name="username" placeholder="Enter name" required>
  <input type="password" name="pass" required>
  <input type="checkbox" name="agree"> I agree
  <input type="submit" value="Submit">
</form>
Form Attributes to Remember
  • action — Where to send data (URL)
  • method — GET (visible in URL) or POST (hidden, more secure)
  • required — Browser won't submit if empty
  • placeholder — Hint text inside the field

Links & Images

html · links and images
<!-- Link -->
<a href="https://google.com" target="_blank">Visit Google</a>

<!-- Image -->
<img src="photo.jpg" alt="A photo" width="300" height="200">

<!-- Figure with caption (semantic) -->
<figure>
  <img src="photo.jpg" alt="Sunset">
  <figcaption>Beautiful Sunset</figcaption>
</figure>
💡 <figure> vs <img>

<img> = just the image. <figure> = image + context/caption. Use <figure> when you want to add a description below the image. Think of <figure> as a picture frame with a label!

CSS — Making Things Look Beautiful
▼
🍼 Think of it like this

If HTML is the skeleton, CSS is the skin, clothes, and makeup! It controls colors, fonts, spacing, layout — everything visual. Without CSS a website looks like a plain text document.

CSS Syntax

css · basic syntax
/* selector { property: value; } */

p {
  color: blue;
  font-size: 16px;
}

/* Class selector */
.highlight { background-color: yellow; }

/* ID selector */
#header { font-size: 24px; }

/* Multiple selectors */
h1, h2, h3 { color: red; }

3 Ways to Add CSS

MethodWhereUse When
InlineInside HTML tag: style="..."Quick one-off tweaks
Internal<style> in <head>Single-page styles
ExternalSeparate .css file, linked with <link>Best practice — reusable across pages

The Box Model 📦

🍼 Analogy

Think of a box inside a box. The innermost is the content (text/image). Around it is padding (cushioning). Then a border (wall). Outside the border is margin (space between this box and others).

css · box model
.box {
  width: 200px;        /* content width */
  padding: 20px;      /* space INSIDE border */
  border: 2px solid black;
  margin: 10px;       /* space OUTSIDE border */
}
Remember: PCBM order (Content → Padding → Border → Margin)
  • Content — The actual text or image
  • Padding — Space between content and border (inside)
  • Border — The visible line/wall around the element
  • Margin — Space outside the border (between elements)
🧠 Memory Trick

Please Bring More Chocolate = Padding, Border, Margin (from inside out!)

XML, DTD, XSD, DOM, SAX, XHTML
▼

XML — eXtensible Markup Language

🍼 Simple idea

XML is like HTML but you make up your own tags. It's used to store and transport data between systems — like a universal language for computers to talk to each other.

xml · employee example
<?xml version="1.0" encoding="UTF-8"?>
<employees>
  <employee id="1">
    <name>John Doe</name>
    <department>Engineering</department>
    <salary>50000</salary>
  </employee>
</employees>
XML Rules (must follow for "Well-Formed")
  • Must have exactly ONE root element
  • All tags must be properly nested (closed in correct order)
  • Attribute values must be in quotes
  • Tags are case-sensitive!

DTD vs XML Schema (XSD)

🍼 Analogy

Both DTD and XSD are like a rulebook for an XML document. They say "this document must have these tags, in this order". The difference: XSD is the newer, more powerful rulebook!

FeatureDTDXSD (XML Schema)
SyntaxCustom, simplerWritten in XML itself
Data TypesLimitedRich (string, integer, decimal...)
Namespaces❌ No✅ Yes
Inheritance❌ No✅ Yes
Used inOlder systems, XHTMLModern XML, SOAP

DOM vs SAX Parsers

🍼 Analogy

DOM parser = Read the entire book, then answer questions. SAX parser = Read the book line by line and react as you go — great for huge books (files) since you don't need to load everything at once.

DOM ParserSAX Parser
Loads whole file?✅ Yes (into memory)❌ No (event-based)
Memory useHighLow
Random access?✅ Yes❌ Sequential only
Best forSmall-medium files; need to navigateLarge files; streaming

XHTML in a Nutshell

XHTML = HTML + XML strictness
  • All tags must be lowercase
  • All tags must be closed (even <br />)
  • All attribute values in quotes
  • Must have a single root element
  • Needs a DOCTYPE declaration

JavaScript — Making Pages Interactive
▼
🍼 Simple idea

If HTML = bones, CSS = skin/clothes, then JavaScript = muscles. JS makes things move and respond. Click a button → something happens. That's JS!

var vs let vs const

Data Types (Primitives)

javascript · primitives

Control Flow

javascript · if / switch / loops
// If-else
if (age >= 18) { console.log("Adult"); }
else { console.log("Minor"); }

// Switch
switch (day) {
  case "Mon": console.log("Monday!"); break;
  default: console.log("Other day");
}

// For loop
for (let i = 0; i < 5; i++) { console.log(i); }

// For...of (arrays)
for (const fruit of fruits) { console.log(fruit); }

// While
while (count < 10) { count++; }

Functions (7 Types!)

javascript · function types
// 1. Declaration
function add(a, b) { return a + b; }

// 2. Expression

// 3. Arrow Function (ES6) — shortest!

// 4. IIFE — runs immediately!
(function() { console.log("I run right now!"); })();

// 5. Async function

}

// 6. Generator
function* gen() { yield 1; yield 2; }

JSP — JavaServer Pages (Dynamic Java Web Pages)
▼
🍼 Simple idea

JSP is like PHP but for Java. You embed Java code inside HTML pages. The server runs the Java, builds the HTML, and sends the result to the user's browser.

JSP Tag Types — The 4 Tags to Know

jsp · all important tags
<!-- 1. DIRECTIVE — page-level settings -->
<%@ page language="java" contentType="text/html" %>
<%@ include file="header.jsp" %>
<%@ taglib uri="/tld/mylib" prefix="my" %>

<!-- 2. DECLARATION — declare variables/methods -->
<%!
  int count = 0;
  void increment() { count++; }
%>

<!-- 3. SCRIPTLET — run Java code -->
<%
  String name = request.getParameter("name");
  if (name != null) { out.println("Hello, " + name); }
%>

<!-- 4. EXPRESSION — output a value -->
<p>Welcome, <%= name %>!</p>
🧠 Memory: D-D-S-E

Directive = @ symbol | Declaration = ! | Scriptlet = just <% %> | Expression = = sign

JSP Implicit Objects (auto-available, no import needed!)

ObjectTypeUsed For
requestHttpServletRequestGet form params, headers, cookies from client
responseHttpServletResponseSend redirects, set cookies
outJspWriterWrite HTML to browser: out.println()
sessionHttpSessionStore user data across pages
applicationServletContextApp-wide data shared by all users
pageObject (this)Reference to current JSP page

JSP Scope Values

ScopeLives How LongVisible To
pageCurrent page onlyOnly this JSP page
requestOne request/response cycleAll components in same request
sessionUntil logout / session timeoutAll pages for same user
applicationUntil server restartsAll users, all pages
📏 Scope size from smallest to biggest

page → request → session → application (think: me → this trip → my whole visit → everyone in the store)

Cookies vs Sessions (Session Tracking)

CookiesSessions
Stored onClient's browserServer
Size limit4KBMuch larger
SecurityLess secure (visible)More secure
LifetimeSet by setMaxAge()Until timeout/logout

JSP Processing Flow

1
Client Request — Browser asks for a .jsp page
2
Translation — Web container (Tomcat) converts JSP → Java Servlet
3
Compilation — Java compiler compiles Servlet → bytecode
4
Execution — JVM runs the bytecode, executes Java code
5
Response — Generated HTML sent back to browser
⚡ Note

Steps 2 & 3 only happen ONCE (first request). After that, the compiled servlet is reused — making JSP faster on subsequent requests!

PHP — Server-Side Scripting Powerhouse
▼
🍼 What is PHP?

PHP runs on the SERVER (not in the browser). You write PHP in a .php file, the server reads it, runs the code, and sends only HTML back to the user. The user never sees PHP code!

PHP Basics Syntax

php · basics
<?php
// Variables start with $
$name = "Alice";
$age = 25;
$price = 9.99;
$active = true;

// Output
echo "Hello, $name! You are $age years old.";

// Concatenation with dot (.)
echo "Hi " . $name . "!";
?>
PHP Key Features
  • Variables always start with $
  • No type declaration needed — PHP figures it out
  • Use echo to print output
  • Concatenation uses dot (.), not +
  • Statements end with semicolon (;)
  • Code goes between <?php and ?> tags

Decision Making & Loops

php · if / switch / loops
// if-elseif-else
if ($score >= 90) { echo "A"; }
elseif ($score >= 80) { echo "B"; }
else { echo "Fail"; }

// While loop
$x = 1;
while ($x <= 5) { echo $x; $x++; }

// For loop
for ($i = 0; $i < 5; $i++) { echo $i; }

// Foreach loop (for arrays)
$fruits = ["apple", "banana", "cherry"];
foreach ($fruits as $fruit) { echo $fruit; }

Arrays in PHP

php · arrays
// Indexed array
$cars = ["Volvo", "BMW", "Toyota"];
echo $cars[0];   // Volvo

// Associative array (key => value)
$person = ["name" => "John", "age" => 30];
echo $person["name"];   // John

// Useful array functions
count($arr);           // count elements
array_push($arr, "x"); // add to end
sort($arr);             // sort ascending
array_merge($a, $b);   // merge two arrays

Functions in PHP

php · functions
// Define a function
function greet($name = "Guest") {  // default param
  return "Hello, " . $name . "!";
}

// Call it
echo greet("Alice");   // Hello, Alice!
echo greet();          // Hello, Guest!

Form Processing in PHP

php · handling form submission
<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
  // Get data safely (prevent XSS)
  $username = htmlspecialchars($_POST["username"]);

  if (empty($username)) {
    echo "Username required!";
  } else {
    echo "Hello, $username!";
  }
}
?>
Security! Always sanitize inputs
  • htmlspecialchars() — prevents XSS (Cross-Site Scripting)
  • empty() — checks if field is empty
  • $_POST — gets form data from POST requests
  • $_GET — gets data from URL query strings

Cookies & Sessions in PHP

php · cookies and sessions
// Set a cookie
setcookie("username", "John", time() + 3600, "/");
// Read it
echo $_COOKIE["username"];

// =====================

// Start session (MUST be first line!)
session_start();
// Store in session
$_SESSION["username"] = "John";
// Read session
echo $_SESSION["username"];
// Destroy session (logout)
session_destroy();

File Handling in PHP

php · file operations
// Open → Read → Close
$file = fopen("data.txt", "r");
$content = fread($file, filesize("data.txt"));
fclose($file);

// Write to file (overwrites)
$file = fopen("data.txt", "w");
fwrite($file, "Hello!");
fclose($file);

// Check if file exists
if (file_exists("data.txt")) { echo "Found!"; }

// Delete file
unlink("data.txt");
File Open Modes (important!)
  • "r" — Read only (file must exist)
  • "w" — Write (creates/overwrites file)
  • "a" — Append (add to end, create if not exists)
  • "r+" — Read and write

PHP + MySQL — Working with Databases
▼
🍼 Simple idea

MySQL is like a giant Excel spreadsheet stored on the server. PHP connects to it, asks for data (SELECT), adds data (INSERT), changes data (UPDATE), or deletes data (DELETE). Then PHP shows the results as HTML.

Connect to MySQL

php · database connection
<?php
$conn = mysqli_connect(
  "localhost",   // server
  "username",    // MySQL user
  "password",    // MySQL password
  "mydb"         // database name
);

if (!$conn) {
  die("Connection failed: " . mysqli_connect_error());
}
echo "Connected!";
?>

CRUD Operations — The 4 core operations

🧠 CRUD = Create, Read, Update, Delete

In SQL: CREATE → INSERT | READ → SELECT | UPDATE → UPDATE | DELETE → DELETE

php+mysql · CRUD operations
// CREATE TABLE
$sql = "CREATE TABLE users (
  id INT AUTO_INCREMENT PRIMARY KEY,
  username VARCHAR(50) NOT NULL,
  email VARCHAR(50) NOT NULL
)";
mysqli_query($conn, $sql);

// INSERT (Create)
$sql = "INSERT INTO users (username, email)
         VALUES ('john', 'john@example.com')";
mysqli_query($conn, $sql);

// SELECT (Read)
$sql = "SELECT * FROM users";
$result = mysqli_query($conn, $sql);
while ($row = mysqli_fetch_assoc($result)) {
  echo $row["username"];
}

// UPDATE
$sql = "UPDATE users SET email='new@mail.com'
         WHERE username='john'";
mysqli_query($conn, $sql);

// DELETE
$sql = "DELETE FROM users WHERE username='john'";
mysqli_query($conn, $sql);

// Always close connection when done!
mysqli_close($conn);

Database Management Commands

sql · database commands
-- Create database
CREATE DATABASE myapp;

-- See all databases
SHOW DATABASES;

-- See all tables in current DB
SHOW TABLES FROM myapp;

-- Add a column to existing table
ALTER TABLE users ADD COLUMN age INT;

-- Drop (delete) a table
DROP TABLE users;

-- Drop (delete) a database
DROP DATABASE myapp;  -- ⚠️ IRREVERSIBLE!

State Management in Web Apps

🍼 The problem

HTTP is stateless — each page load is completely fresh, like calling someone who forgets who you are each time you call. We need tricks to "remember" users between requests.

MethodStored OnBest For
CookiesBrowserRemember preferences, session ID (max 4KB)
SessionsServerSecure user data, login state
Query StringsURL (?key=val)Passing data between pages (NOT for sensitive data!)
URL Path ParamsURL (/users/42)RESTful APIs, clean URLs
DatabaseServer DBPersistent data (orders, profiles)
Local StorageBrowserLarge client-side data, persists after close

Serialization

🍼 Simple idea

Serialization = converting an object/data into a string so it can be sent over a network or saved to a file. Like turning a 3D sculpture into a 2D blueprint to mail it, then rebuilding it on the other side (deserialization).

Common Serialization Formats
  • JSON — Most popular for web APIs. Human-readable, compact.
  • XML — Verbose but widely supported. Great for SOAP.
  • Protocol Buffers / MessagePack — Binary. Smaller and faster but not human-readable.

PHPMyAdmin — Visual Database Manager

What PHPMyAdmin lets you do
  • Create / delete databases and tables (no SQL needed — click buttons)
  • Import and export SQL files for backup
  • Run SQL queries directly
  • Manage user privileges
  • Accessed at: http://localhost/phpmyadmin/
